# Voice

Optional. Copy this file to `voice.md` and describe how you write; the CV writer follows it
(facts always win over style). Without a `voice.md` it writes plainly.

- Plain verbs and concrete specifics. A named example beats a general claim.
- No clichés: passionate, results-driven, dynamic, leverage, seamless, robust.
- Digits for numbers. No exclamation marks.
- British spelling unless the employer's listing is clearly in US English.
